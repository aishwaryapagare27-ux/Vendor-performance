# 📊 Vendor Performance Analysis

## 📌 Project Overview

Vendor Performance Analysis is a Data Analytics project focused on evaluating vendor performance, analyzing purchasing and sales data, and identifying opportunities to improve profitability and inventory management.

The project uses Python, SQL, SQLite, and Power BI to transform raw data into meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives

- Analyze vendor-wise purchasing and sales performance.
- Identify top-performing and low-performing vendors.
- Evaluate purchase contribution and sales trends.
- Analyze inventory levels and identify slow-moving stock.
- Understand profitability and cost efficiency.
- Create an interactive Power BI dashboard for business insights.

## 📂 Project Workflow

1. **Data Collection** – Gather vendor, purchase, sales, and inventory data.
2. **Data Cleaning** – Handle missing values, duplicates, and inconsistencies using Python.
3. **Data Processing** – Transform and organize the data for analysis.
4. **Database Management** – Store and manage structured data using SQLite.
5. **Exploratory Data Analysis (EDA)** – Analyze trends, patterns, and relationships.
6. **Data Visualization** – Create charts and graphs to understand vendor performance.
7. **Dashboard Development** – Build an interactive Power BI dashboard.
8. **Business Insights** – Identify opportunities to improve vendor and inventory performance.
